## 3. Risks & mitigations

| Risk | Mitigation |
|---|---|
| A provider name or URL shape leaks outside its crate/registry | `provider_name_guard.mjs` in `globalSetup` and `node --test`; ask "would this work unchanged for a second provider?" |
| A credential reaches a build, fixture, log, doc or screenshot | Runtime entry only; `docs/Providers.md` (Credentials) grep gates; the one hosted-demo exception is bounded in §6.1 |
| A test reaches the network | Committed fixtures under `/providers/{provider_key}/…`; the GPU harness runs outside `npm test` |
| A stale base layer or fallback serves the wrong provider | M54's precedence rule and origin-counting proofs; the renderer invalidates its vector cache on install/clear |
| Generated surfaces drift from the UDL | `contract_sync.mjs` plus the M57 generation gate |
| everymap-rs lags a capability the SDK needs | The upstream build-out is gated per capability by its own contract test, and this SDK keeps the current traits until parity; the switch lands only after the wasm build and every suite are green (M66) |
| Tile fetchers overwhelm a provider or the browser's connection pool | Descriptor-declared pacing sized for the 8-permit pool, retry and cancellation, and a descriptor value per provider rather than one global rate (M65) |
| PLAN/CHANGELOG drift from the tree | This prune (2026-11-02): checklists only, one-liners for completed work, dated log |
