# Maintainers

Maintainers are listed by area. The same list, with access levels, is maintained
in the repository settings; this page states who reviews what.

| Area | Maintainer |
|---|---|
| Core and renderer | @angoratek |
| Providers | @angoratek |
| Android | @angoratek |
| iOS | @angoratek |
| React Native | @angoratek |
| WebAssembly | @angoratek |
| Documentation and release | @angoratek |

A path belongs to the area that owns it. The path-to-reviewer mapping is in
[`.github/CODEOWNERS`](.github/CODEOWNERS). Governance and the process for
adding a maintainer are in [`GOVERNANCE.md`](GOVERNANCE.md).
