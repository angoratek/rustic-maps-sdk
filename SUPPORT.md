# Support

## Questions and usage help

Ask a question in [GitHub Discussions](https://github.com/angoratek/rustic-maps-sdk/discussions).
Include the platform, the version or commit, and the smallest code sample that
shows what you are trying to do.

## Documentation

The published guide is at <https://angoratek.github.io/rustic-maps-sdk-docs/>.
It covers installation, the first map, search and routing, turn-by-turn
navigation, offline maps, the API reference, and the live browser demo.

## Bugs and feature requests

Open a [GitHub issue](https://github.com/angoratek/rustic-maps-sdk/issues/new/choose).
Use the bug report form for a defect and the feature request form for a change.
Include reproduction steps, the platform, and the version or commit.

## Security

Never report a security issue in an issue or a discussion. Follow
[`SECURITY.md`](SECURITY.md) and use the private advisory flow.
